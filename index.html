⚙️ Firebase Realtime Database einrichten

Einmalige Einrichtung (ca. 3 Minuten)

Damit alle Besucher dieselben Artikel sehen und bearbeiten können, brauchst du eine kostenlose Firebase-Datenbank von Google.

  1. Gehe zu console.firebase.google.com und melde dich an.
  2. Klicke „Projekt hinzufügen", gib einen Namen ein, klicke durch bis „Projekt erstellen".
  3. Links im Menü: Erstellen → Realtime Database → „Datenbank erstellen".
  4. Standort wählen → „Im Testmodus starten" → Fertig stellen.
  5. Du siehst jetzt die Datenbank-URL: https://DEIN-PROJEKT-default-rtdb.firebaseio.com → merken!
  6. Gehe zu ⚙️ Projekteinstellungen (Zahnrad oben links) → Allgemein.
  7. Scrolle zu „Deine Apps" → Klicke das Web-Symbol </> → App registrieren.
  8. Du siehst ein firebaseConfig-Objekt mit allen Werten → trage sie unten ein.

💡 Die Werte werden nur in deinem Browser (localStorage) gespeichert. Für Produktion: Firebase-Datenbankregeln anpassen, damit nur du schreiben kannst.
